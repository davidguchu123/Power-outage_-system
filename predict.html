Outage Prediction

Select an area to run the prediction algorithm implemented in C++. Uses SimplePrediction — a derived class of the abstract PredictionSystem.

🫧 Abstraction + 🎭 Polymorphism: The prediction system uses an abstract base class PredictionSystem with a pure virtual predictOutage() method. SimplePrediction extends it and provides the concrete implementation. The frontend calls the backend via the CGI API, which internally uses a PredictionSystem* pointer to call predictOutage() polymorphically.

🧠 Prediction Algorithm (C++ SimplePrediction)

The SimplePrediction class extends the abstract PredictionSystem and implements a frequency-based prediction model:

  • 📊 Count total outages in the target location
  • ⏱️ Compute average duration of resolved outages
  • 🔴 ≥5 outages → HIGH risk
  • 🟡 2–4 outages → MEDIUM risk
  • 🟢 1 outage → LOW risk
  • ⚪ 0 outages → No history
// [ABSTRACTION] Abstract base class
class PredictionSystem {
public:
  // Pure virtual = abstract method
  virtual void predictOutage(
    OutageReport* reports,
    int count
  ) = 0;
};
